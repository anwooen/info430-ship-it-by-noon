# My app

**Domain:** Study session tracker for college students.

**User story:** As a college student, I need to see my study sessions and total study time for each course during a selected date range, so that I can decide which courses need more attention.

**What the user types or picks:** A course (or all courses), a start date, and an end date.

**What the app shows:** Matching study sessions with the course, date, topic, and duration, plus total study minutes by course.
